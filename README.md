# CheXNet

PyTorch implementation of CheXNet for chest X-ray classification and model interpretability using Grad-CAM.

## Implementations

### 1. CheXNet-Baseline
- Chest X-ray multi-label classification
- Prediction of 14 thoracic disease labels

### 2. CheXNet-GradCAM
- Visualization of class-discriminative regions
- Model interpretability using Grad-CAM

## Dataset
